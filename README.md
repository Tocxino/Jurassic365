# Jurassic 365

Página para calificar un dinosaurio nuevo cada día.

- `index.html`: estructura de la página
- `css/styles.css`: estilos
- `js/config.js`: **aquí van la URL de la API (/exec) y el Client ID de Google**
- `js/api.js`: llamadas a la API de Apps Script
- `js/app.js`: galería, detalle, votación, ranking y cuenta regresiva
- `img/silueta-trex.svg`: silueta para los días bloqueados y los dinos sin imagen

Los datos viven en Google Sheets y solo se entregan a través de la API de Apps Script.
